# ByUs UI Clone

모바일 앱 ByUs의 인터페이스를 HTML/CSS/JS로 재현한 정적 사이트입니다. 이미지 자산은 포함하지 않으며 그라디언트 플레이스홀더로 대체했습니다.

## 실행

`index.html`을 브라우저에서 바로 열거나, 정적 서버로 서빙합니다.

```
npx serve .
```

## 화면

- `#home` 홈 (진행 중인 스토리 / 지금 인기있는 스토리)
- `#chat` 대화
- `#create` 만들기
- `#more` 더보기
- `#notice` 알림 (홈 상단 종 아이콘으로 진입)

## 구조

- `index.html` 다섯 화면 마크업과 하단 탭바
- `css/style.css` 다크 테마 스타일
- `js/app.js` 대화/알림 목록 데이터, 탭 전환, 칩 선택
